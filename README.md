# Portafolio de Diego

Sitio estático con el portafolio profesional y proyectos web de demostración.

## Publicar en Vercel

El proyecto no requiere proceso de compilación. `index.html` es el portafolio y se sirve directamente en la ruta principal `/`.

## Páginas

- `index.html`: página principal y portafolio profesional.
- `crm.html`: demo interactiva de CRM.
- `inventario.html`: demo interactiva de inventario.
- `viajes.html` y `veterinaria.html`: otros proyectos de muestra.
